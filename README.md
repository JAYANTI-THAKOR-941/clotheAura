# ClothAura — Django Clothing Store

Django clothing storefront with product pages, cart, checkout, orders, profile, OTP verification and administration templates.

## Project structure

- `ClothAura/`
- `main/models.py`
- `main/views.py`
- `main/templates/main/`
- `requirements.txt`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/clotheAura.git
cd clotheAura
```

Create a virtual environment, install `pip install -r requirements.txt`, configure local settings, then run `python manage.py migrate` and `python manage.py runserver`.
